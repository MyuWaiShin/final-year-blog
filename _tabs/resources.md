# Resources & References

This page contains useful tutorials, documentation, code repositories, and learning materials related to the project. It's designed to help anyone interested in replicating this work or exploring similar topics.

> **Note:** This is different from the [Literature Review](/final-year-blog/literature-review/) page, which focuses on academic papers and research publications.

---

## Robot Control & Programming

### Universal Robots (UR10)
- **[UR+ Platform](https://www.universal-robots.com/plus/)** - Official Universal Robots ecosystem and resources
- **[URSim Download](https://www.universal-robots.com/download/)** - Download URSim simulator for offline programming
- **[UR Python Library (ur_rtde)](https://sdurobotics.gitlab.io/ur_rtde/)** - Real-time data exchange with UR robots using Python
- **[UR Script Manual](https://s3-eu-west-1.amazonaws.com/ur-support-site/115824/scriptManual_SW5.11.pdf)** - Complete URScript programming reference

### Tutorials
- **[Getting Started with UR Robots](https://academy.universal-robots.com/)** - Official UR Academy with free courses
- **[Python UR Control Examples](https://github.com/jkur/python-urx)** - Python library examples for UR robot control

## Computer Vision & Object Detection

### YOLO (You Only Look Once)
- **[Ultralytics YOLOv8](https://github.com/ultralytics/ultralytics)** - Latest YOLO implementation with excellent documentation
- **[YOLOv8 Training Tutorial](https://docs.ultralytics.com/modes/train/)** - Official guide for training custom YOLO models
- **[Roboflow](https://roboflow.com/)** - Dataset management and annotation tool for YOLO training
- **[YOLO Object Detection Explained](https://www.youtube.com/watch?v=ag3DLKsl2vk)** - Comprehensive video tutorial

### Pose Estimation
- **[6D Pose Estimation Overview](https://github.com/zubair-irshad/Awesome-Implicit-NeRF-Robotics#6d-object-pose-estimation)** - Collection of pose estimation resources
- **[OpenCV Pose Estimation](https://docs.opencv.org/4.x/d7/d53/tutorial_py_pose.html)** - Tutorial using OpenCV's solvePnP
- **[DenseFusion](https://github.com/j96w/DenseFusion)** - RGB-D based 6D pose estimation
